# React + Vite TodoList App

A modern, beautiful TodoList application built with React, Vite, and TypeScript.

## Features

- Add, edit, and delete todos
- Mark todos as complete/incomplete
- Filter todos (All, Active, Completed)
- Persistent storage with localStorage
- Beautiful, modern UI with animations
- Responsive design

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- Vite
- TypeScript
- CSS Modules
