# Interview Knowledge Base

这里集中整理 AI Agent 相关面试题，负责复习和索引，不重复 `lessons/` 中的教学实现。

- 从面试问题出发，练习可直接表达的回答。
- 通过 Lesson 链接回正式课程、源码和理论知识。
- 用覆盖状态暴露学习缺口，面试前可按主题快速复习。
- 题目原文中的图片要嵌入对应 Markdown，并与题目按相同编号顺序保存和引用。

题目和图片按连续、等宽编号维护。例如单篇文档中的题目按 `Q1`、`Q2` 顺序排列，图片资源使用 `01-q1-*.png`、`02-q2-*.png` 等名称，并在对应题目下用相对路径引用。
